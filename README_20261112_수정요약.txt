MY NEWS 365 수정 요약 (2026-11-12)
===================================

반영 사항
1) 메인 로고 교체
- 사용자가 첨부한 정사각형 N 로고를 기준으로 brand-logo.svg, brand-icon.svg,
  icon-192.png, icon-512.png, apple-touch-icon.png, favicon-32.png를 갱신했습니다.

2) 오늘의 주요 뉴스 TOP 5 개선
- 기존: 같은 기사/대표사진이 반복적으로 보이는 경우가 많음
- 변경: 새로고침 때마다 분야별 최신 기사 후보를 다시 선택해 표시
- 기사 사진이 있으면 기사 사진 우선, 없을 때만 분야 대표 이미지 사용
- 분야 구성: 정치 / 경제 / 문화 / 국제 / IT
- 사회 섹션은 문화 섹션으로 교체
- Netlify Function(headlines.js)은 네이버 뉴스 검색 결과를 우선 시도하고,
  실패 시 Google 뉴스 RSS로 자동 대체하도록 구성했습니다.

3) 언론사·기관 바로가기 확장
- 종합지, 방송, 경제/IT, 지역신문, 스포츠, 전문지 등을 추가했습니다.
- '시청·도청 보도자료'는 시·도 + 시·군·구 선택 구조로 유지됩니다.

4) 모바일 보완
- 하단 도크 메뉴와 겹침을 줄이도록 추가 여백을 보완했습니다.
- Netlify 'Powered by Netlify' 배지는 프로젝트 설정에서 Off 하는 것이 가장 확실합니다.

배포 방법
- ZIP을 풀어서 GitHub 저장소 루트에 같은 경로로 덮어쓰기 업로드 후 Netlify 재배포
- 서비스워커 캐시가 남아 있으면 브라우저 새로고침 또는 앱 재실행 필요
