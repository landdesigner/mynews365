- 시·도 + 시·군·구 지역 선택 유지, 지역 뉴스 최대 6건

- 신문사/기관 디렉터리 검색 및 즐겨찾기 유지, 목록은 처음 12개(PC 24개) 표시 후 더 보기

- 운영자 로그인, 공개 댓글, 의견 접수는 포함하지 않음

[배포]
1. ZIP 압축을 풀고 안의 파일과 폴더를 GitHub landdesigner/mynews365 저장소 루트에 올립니다.
2. 기존 파일은 교체하고 새 premium-app.css / premium-ui.js를 반드시 추가합니다.
3. netlify/functions/ 아래 파일도 기존 경로에 올립니다.
4. GitHub Commit changes 후 Netlify Deploys에서 Published 확인.
5. 브라우저 새로고침(필요하면 시크릿 창) 후 모바일 화면 확인.

[참고]
- 뉴스는 Google News RSS를 통해 수집되며 원본 기사로 연결합니다. 기사 제공 상황에 따라 항목 수가 적을 수 있습니다.
- TOP 5 숫자는 최신 기사 배열 표기이지 중요도 순위가 아닙니다.
- 위치 GPS나 로그인을 요구하지 않습니다. 선택 지역과 키워드는 해당 브라우저의 localStorage에 보관됩니다.
- 사이트에 있는 뉴스 표시 기능은 Netlify Functions 배포가 필요합니다.
