신문 바로가기 설치 안내

1. 이 ZIP 파일을 압축 해제합니다.
2. Netlify Drop (https://app.netlify.com/drop)에서 압축 해제한 폴더 전체를 업로드합니다. (ZIP 자체를 받는 방식은 서비스 화면에 따라 다를 수 있습니다.)
3. 발급된 https://...netlify.app 주소를 아이폰 Safari에서 엽니다.
4. 공유 > 홈 화면에 추가 > 추가를 누릅니다.

주의: 실제 공개 주소는 업로드 후 발급됩니다. 즐겨찾기는 기기/브라우저별로 저장됩니다. 신문사 사이트는 인터넷 연결이 필요합니다.
