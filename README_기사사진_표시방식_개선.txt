MY NEWS 365 — 실제 기사 사진만 표시하는 개편판
============================================

적용 내용
- TOP 5: 기사 원문·RSS 사진 URL이 제공되는 경우에만 사진 표시.
- 사진 URL이 없거나 이미지 로딩에 실패하면 반복 대표 사진 대신 제목 중심 텍스트 카드.
- 내 지역 최신 뉴스: 첫 번째 기사에 실제 사진이 있는 경우에만 사진 표시.
- 고정된 분야 대표 사진과 풍경 사진을 뉴스 카드에서 사용하지 않음.
- 나만의 관심 뉴스, 지역 선택, 문화 섹션, 신문사 디렉터리 및 모바일 메뉴 유지.

적용 방법
ZIP을 압축 해제하고 GitHub 저장소에 폴더 구조 그대로 업로드합니다.
특히 index.html, news-widgets.js, no-placeholder-photo.css, sw.js가 함께 업로드되어야 합니다.
Netlify 배포 후 브라우저 강력 새로고침. PWA 캐시가 오래된 경우 앱을 재실행하세요.

주의
- 외부 기사 이미지는 언론사가 외부 표시를 차단하면 로딩되지 않을 수 있습니다.
- 뉴스 헤드라인은 기존 Netlify Functions로 가져옵니다. 실제 뉴스 데이터는 배포 환경에서 확인해야 합니다.
