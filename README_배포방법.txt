MY NEWS 365 통합 업데이트

기존 GitHub 저장소 landdesigner/mynews365 의 최상위에 이 폴더 안의 파일을 올리세요. netlify/functions/headlines.js 폴더 구조를 그대로 유지해야 합니다.
Netlify에 연결된 main 브랜치에 커밋하면 기존 mynews365.netlify.app 주소에 자동 배포됩니다.
기존 즐겨찾기는 브라우저 저장소에 유지되며 기기간 자동 동기화되지는 않습니다.
새 앱 아이콘이 보이지 않으면 홈 화면 바로가기를 삭제 후 다시 추가하세요.
뉴스는 Google News RSS 기반으로 최신순 정렬하며 RSS 제공 상황에 따라 지연될 수 있습니다.
