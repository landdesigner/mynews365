MY NEWS 365 — 2026-11 개선사항

1. 나만의 관심 뉴스: 최초 5건 + 더 보기 버튼을 누를 때마다 추가 최대 5건, 전체 최대 20건. 실제 검색 결과가 부족하면 적게 표시됩니다.
2. 언론사 카드: 로고 중심의 2~5열 반응형 카드 + 이름 + 분야 + 즐겨찾기 별표. 아이콘이 없는 경우 언론사 이니셜을 표시합니다.
3. 04 / NEWS DIRECTORY: 중복된 작은 빠른 바로가기 패널 제거. 전체 언론사 목록 하나만 유지.
4. 시청·도청 보도자료: 시도 17곳 선택, 시군구 선택, 공식 보도자료 바로가기(확인된 기관) 및 기관 소식 검색. 경북 구미시/안동시/경산시/경북도청은 보도자료 직접 링크를 사용하며 일부 기관은 공식 홈페이지를 연결합니다. 확인되지 않은 기관은 임의의 공식 URL을 만들지 않고 별도 검색으로 안내합니다.
5. 최신 PC 및 모바일 프리미엄 네이비/민트, 지역 뉴스, 주요 뉴스, 키워드, 사진 표시 기능 모두 유지.

설치: ZIP의 파일과 폴더를 GitHub 저장소 최상단에 업로드(폴더 구조 유지) > Commit changes > Netlify Published 확인.
수정된 주요 파일: index.html, news-widgets.js, netlify/functions/topic-news.js, sw.js
새 파일: directory-upgrade.js, directory-upgrade.css

주의: 보도자료 링크/정부 사이트 구조가 변경될 수 있으므로 공식 사이트 또는 검색으로 이동하도록 병행했습니다.
