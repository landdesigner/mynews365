MY NEWS 365 | 실제 기사사진 · 언론사 아이콘 · 관심 뉴스 최신 5건
=================================================================

핵심 개선
  1. 기사 사진 자동 표시: RSS의 media:thumbnail/media:content 등 → 언론사 페이지의 og:image(가능할 때) → 기존 대표 사진 순으로 표시합니다.
     Google 뉴스 링크는 출처 URL 확인이 까다롭고 언론사 사이트 정책에 따라 이미지 추출이 실패할 수 있습니다.
     이 경우 '기사 사진'이라는 잘못된 표시 대신 '분야 대표 사진/대표 풍경 사진'이 나타납니다.
  2. 언론사 바로가기: 각 사이트의 파비콘(작은 공식 사이트 아이콘)을 자동 불러와 신문사명 옆에 표시합니다.
     외부 아이콘 서비스가 차단되면 신문사 이름의 앞 두 글자를 대신 표시합니다.
  3. 나만의 관심 뉴스: 선택 키워드의 최신 5건만 표시하며, 기사 사진이 제공된 경우 작은 썸네일을 함께 보여줍니다.
     기존 키워드 정확한 제목 매칭, 최근 10년 이전 기사 제외, 새로고침, 기기별 저장 기능은 유지됩니다.
  4. 기존 모바일 하단 메뉴와 Netlify 배지 겹침 방지 여백을 유지합니다.

업로드 방법
  1. ZIP을 풀고 GitHub landdesigner/mynews365 저장소로 이동
  2. Add file → Upload files를 선택하여 압축 해제된 파일을 폴더 구조 그대로 업로드
  3. 반드시 netlify/lib/news-photo.js (새 파일)도 올려야 기사 사진 검색이 작동합니다.
  4. netlify/functions/headlines.js 및 topic-news.js, index.html, news-widgets.js, photo-edition.css 파일도 업데이트
  5. Commit changes 클릭 → Netlify Deploys에서 Published 확인
  6. PC/모바일 새로고침. 홈 화면 설치 앱의 캐시가 남으면 앱 다시 열기 또는 브라우저에서 확인

사진 표시의 한계
  - 사진은 해당 언론사가 외부 사이트 노출을 허용하는 경우에만 성공합니다.
  - RSS·OGP 메타데이터에서 기사 사진을 찾지 못하면 대체 사진으로 표시합니다.
  - 외부 기사를 복제하거나 사진을 로컬에 다운로드/저장하지 않습니다.
  - Google 뉴스 링크 원문 변환은 비공식 기능이라 서비스 제공 방식이 바뀌면 실패할 수 있습니다.
  - 사진 외부 로딩은 사용자 네트워크/보안 차단 설정에 영향을 받을 수 있습니다.

주의: 이메일·댓글 관리자 기능을 다시 도입하지 않았습니다. 가입 또는 API 키가 필요하지 않습니다.
